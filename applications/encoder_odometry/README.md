## 概述

本应用基于Breeze框架实现了一个简单的里程计系统，通过编码器数据计算小车的速度和行驶距离。里程计（Odometry）是移动机器人中用于估计位置和方向的基本技术，本应用展示了如何使用编码器数据实现这一功能。

## 功能特点

1. **实时速度计算**：计算小车的线速度和角速度
2. **距离测量**：计算左右轮分别行驶的距离以及总行驶距离
3. **位置估计**：根据轮子转动计算小车在平面上的位置(x,y)和方向角(theta)
4. **基本运动控制**：支持前进、后退、左转、右转等基本运动控制
5. **里程计重置**：支持重置位置和距离计数

## 硬件要求

- 两个直流电机（左右轮驱动）
- 两个编码器（左右轮速度和位置反馈）
- 电机驱动电路
- 微控制器（如STM32、Arduino等）

## 软件架构

应用由以下几个主要部分组成：

1. **硬件抽象层**：提供电机控制和编码器读取的接口
2. **差速驱动控制器**：使用Breeze框架的差速驱动模块控制小车运动
3. **里程计算法**：根据编码器数据计算小车位置、方向和速度

### 主要数据结构

- **CarState**：小车状态结构体，包含当前位置、方向、速度和累计距离
- **EncoderOdometry**：里程计应用结构体，包含控制器和状态信息

## 里程计原理

里程计基于以下原理工作：

1. **编码器计数**：编码器随着轮子转动产生脉冲，通过计数这些脉冲可以测量轮子转过的角度
2. **距离计算**：轮子转过的角度乘以轮子半径可以计算出行驶距离
3. **位置更新**：根据左右轮的距离差计算转向角度，结合行驶距离更新位置坐标

### 数学模型

差速驱动小车的运动学模型如下：

- 线速度 v = (v_left + v_right) / 2
- 角速度 ω = (v_right - v_left) / L

其中，v_left和v_right分别是左右轮的线速度，L是左右轮之间的距离。

位置更新公式：
- Δθ = (Δright - Δleft) / L
- Δdist = (Δleft + Δright) / 2
- x = x + Δdist * cos(θ)
- y = y + Δdist * sin(θ)

其中，Δleft和Δright分别是左右轮的距离增量，θ是小车的方向角。

## 里程计精度与误差

里程计存在以下误差来源：

1. **系统误差**：
   - 轮子直径测量不准确
   - 轮子之间距离测量不准确
   - 编码器分辨率有限

2. **随机误差**：
   - 轮子打滑
   - 地面不平整
   - 编码器噪声

3. **累积误差**：
   - 里程计误差会随着时间和距离累积
   - 长距离运行后位置估计可能显著偏离实际位置

### 提高精度的方法

1. **精确测量参数**：准确测量轮子直径和轮子之间的距离
2. **校准程序**：开发校准程序定期校正参数
3. **滤波算法**：使用卡尔曼滤波等算法处理编码器数据
4. **融合其他传感器**：结合IMU、视觉或GPS等其他传感器数据
5. **定期重置**：在已知位置定期重置里程计

## 扩展功能

本应用可以进一步扩展以下功能：

1. **数据记录**：记录位置和速度数据到文件
2. **路径可视化**：实时绘制小车运动轨迹
3. **卡尔曼滤波**：添加卡尔曼滤波器提高位置估计精度
4. **IMU融合**：结合IMU数据实现更准确的姿态估计
5. **闭环控制**：实现基于位置的闭环控制

## 注意事项

1. 里程计只能提供相对位置估计，长时间运行会累积误差
2. 在光滑表面上轮子容易打滑，导致位置估计不准确
3. 初次使用时应校准轮子直径和轮子之间距离参数
4. 对于高精度应用，应考虑结合其他传感器数据
