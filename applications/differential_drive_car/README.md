# 差速驱动小车应用

> **可以编译并运行。** 本示例依赖 `include/breeze/breeze.h`，该头文件曾经因为两处缺陷
> 无法编译，现已修好，详见 [../../docs/REVIEW.md](../../docs/REVIEW.md) §26。
> 本文档描述的是设计意图与算法，保留作为算法层迁移到 Zig 时的对照。
>
> 构建与运行（在本目录下）：`gcc differential_drive_car.c -o differential_drive_car -lm`。
> 程序是交互式的，按 `q` 退出。

## 概述

本应用基于Breeze框架实现了一个差速驱动小车，具有以下功能：

1. **基本运动控制**：前进、后退、左转、右转等基本运动控制
2. **测速测距**：通过编码器数据实时计算小车速度和行驶距离
3. **路径记录**：记录小车运动轨迹，包括位置、方向、速度等信息
4. **路径重放**：按照记录的轨迹重放小车运动

该应用展示了如何使用Breeze框架的差速驱动控制器、PID控制器和数学工具模块来实现一个完整的移动机器人应用。

## 硬件要求

- 两个直流电机（左右轮驱动）
- 两个编码器（左右轮速度和位置反馈）
- 电机驱动电路
- 微控制器（如STM32、Arduino等）

## 软件架构

应用由以下几个主要部分组成：

1. **硬件抽象层**：提供电机控制和编码器读取的接口
2. **差速驱动控制器**：使用Breeze框架的差速驱动模块控制小车运动
3. **状态估计**：根据编码器数据计算小车位置、方向和速度
4. **路径记录与重放**：记录和重放小车运动轨迹

### 主要数据结构

- **PathPoint**：路径点结构体，记录位置、方向、速度和时间戳
- **CarState**：小车状态结构体，包含当前位置、方向、速度和累计距离
- **DifferentialDriveCar**：小车应用结构体，包含控制器、状态和路径数据

## 功能说明

### 基本运动控制

小车支持以下基本运动控制命令：

- **前进(w)**：以0.5米/秒的速度前进
- **后退(s)**：以0.5米/秒的速度后退
- **左转(a)**：以0.3米/秒的速度前进并以1.0弧度/秒的速度左转
- **右转(d)**：以0.3米/秒的速度前进并以1.0弧度/秒的速度右转
- **停止(空格)**：停止小车运动

### 测速测距

应用通过编码器数据实时计算以下信息：

- **线速度**：小车前进/后退的速度（米/秒）
- **角速度**：小车旋转的速度（弧度/秒）
- **累计距离**：左右轮分别行驶的累计距离（米）
- **位置估计**：根据轮子转动计算小车在平面上的位置(x,y)和方向角(theta)

### 路径记录

使用路径记录功能可以记录小车的运动轨迹：

1. 按下**r键**开始记录
2. 控制小车按照期望的路径运动
3. 按下**t键**停止记录

记录的路径数据包括：
- 位置坐标(x,y)
- 方向角(theta)
- 线速度(v)
- 角速度(omega)
- 时间戳(timestamp)

路径数据会自动保存到文件`track_data.txt`中。

### 路径重放

使用路径重放功能可以让小车按照之前记录的轨迹运动：

1. 按下**p键**开始重放
2. 小车将自动按照记录的路径运动
3. 按下**o键**停止重放

重放过程中，应用会根据当前时间找到对应的路径点，并使用线性插值计算目标速度，确保小车平滑地沿着记录的路径运动。

## 使用方法

> **注意**：以下编译命令当前**会失败**，原因见文首说明。

1. 编译应用程序（预期失败）：
   ```
   gcc differential_drive_car.c -o differential_drive_car -lm
   ```

2. 运行应用程序：
   ```
   ./differential_drive_car
   ```

3. 使用键盘控制小车：
   - **w**: 前进
   - **s**: 后退
   - **a**: 左转
   - **d**: 右转
   - **空格**: 停止
   - **r**: 开始记录
   - **t**: 停止记录
   - **p**: 开始重放
   - **o**: 停止重放
   - **q**: 退出程序

## 实际应用

在实际应用中，需要根据具体硬件修改以下部分：

1. **硬件抽象层函数**：
   - `set_motor`: 根据实际电机驱动电路实现电机控制
   - `get_encoder`: 根据实际编码器实现编码器读取
   - `get_time`: 使用实际的时间获取函数

2. **差速驱动配置**：
   - 根据实际小车尺寸设置轮子距离和半径
   - 根据实际电机性能设置最大速度
   - 根据实际编码器设置分辨率

## 扩展功能

本应用可以进一步扩展以下功能：

1. **障碍物检测与避障**：添加超声波或红外传感器检测障碍物
2. **路径规划**：实现从起点到终点的自动路径规划
3. **视觉导航**：添加摄像头实现视觉导航
4. **无线控制**：添加蓝牙或WiFi模块实现远程控制
5. **自动充电**：实现自动寻找充电站并充电

## 注意事项

1. 在实际应用中，编码器数据可能存在噪声，建议添加滤波器处理
2. 长时间运行可能导致位置误差累积，建议添加其他传感器（如IMU、视觉）进行位置校正
3. 路径记录文件可能变得很大，建议添加数据压缩或定期清理机制
4. 在重放路径时，应考虑实际环境可能与记录时不同，添加适应性调整机制
