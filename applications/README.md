# Breeze框架应用示例

本目录包含基于Breeze框架开发的完整应用示例，展示了如何使用框架的各个模块构建实际应用。

## 应用列表

### 1. 差速驱动小车 (differential_drive_car)

一个完整的差速驱动小车应用，包含以下功能：

- 基本运动控制（前进、后退、左转、右转）
- 通过编码器数据实现测速和测距
- 路径记录功能，可以记录小车运动轨迹
- 路径重放功能，可以按照记录的轨迹重放小车运动

这个应用展示了如何使用Breeze框架的差速驱动控制器、PID控制器和文件操作来实现一个具有记录和重放功能的移动机器人。

[查看详细说明](differential_drive_car/README.md)

### 2. 基于编码器的里程计 (encoder_odometry)

一个专注于测速和测距功能的里程计应用，包含以下功能：

- 实时计算小车的线速度和角速度
- 测量左右轮分别行驶的距离以及总行驶距离
- 根据轮子转动计算小车在平面上的位置和方向
- 基本运动控制和里程计重置功能

这个应用展示了如何使用编码器数据实现移动机器人的位置估计，是机器人导航的基础。

[查看详细说明](encoder_odometry/README.md)

## 如何使用这些应用

每个应用都包含完整的源代码和详细的README文件，说明其功能、原理和使用方法。要使用这些应用，请按照以下步骤操作：

1. 进入相应的应用目录
2. 阅读README文件了解应用功能和使用方法
3. 编译应用程序：`gcc 应用名.c -o 应用名 -lm`
4. 运行应用程序：`./应用名`

## 在实际硬件上部署

这些应用默认使用模拟的硬件接口函数，要在实际硬件上部署，需要修改以下部分：

1. **硬件抽象层函数**：
   - `set_motor`: 实现实际电机控制
   - `get_encoder`: 实现实际编码器读取
   - `get_time`: 实现实际时间获取

2. **硬件配置参数**：
   - 轮子尺寸和距离
   - 电机和编码器ID
   - 编码器分辨率
   - PID控制参数

## 扩展和定制

这些应用可以作为起点，根据需要进行扩展和定制：

1. **添加更多传感器**：
   - 超声波或红外传感器用于障碍物检测
   - IMU用于姿态估计
   - 摄像头用于视觉导航

2. **添加更多功能**：
   - 自动避障
   - 路径规划
   - 视觉识别
   - 无线通信

3. **优化算法**：
   - 改进位置估计算法
   - 添加滤波器减少噪声
   - 优化控制算法提高稳定性
